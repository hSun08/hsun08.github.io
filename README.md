# Haixiang Sun — Academic Homepage

Customized from [Academic Pages](https://github.com/academicpages/academicpages.github.io).
This package contains the homepage source, assets, and GitHub Pages workflow.

Rename the repository to `hsun08.github.io` for a user homepage without a path suffix.
Upload the contents of this directory to the root of `hSun08/hsun08.github.io`.
The intended published URL is `https://hsun08.github.io/`.
In Settings → Pages, select **GitHub Actions** as the source.
The **Deploy academic homepage** workflow publishes changes on `main` or `master`.

Edit `_data/profile.json` to update content. GitHub rebuilds the site automatically.
For a local build with Node.js 22, run `node scripts/build-home.mjs`.
The complete original template remains available in `haixiang-sun-homepage.zip`.
